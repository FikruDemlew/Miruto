# Miruto

Miruto is a simple, fast, and lightweight Streaming platform for live video streaming.

## Features

- Simple and fast
- Lightweight
- Supports multiple video formats
- Supports multiple audio formats
- Supports multiple video and audio codecs
- Supports multiple video and audio bitrates
- Supports multiple video and audio resolutions
- Supports multiple video and audio framerates
- Supports multiple video and audio channels
- Supports multiple video and audio samplerates
- Supports multiple video and audio audio tracks
- Supports multiple video and audio subtitle tracks
- Supports multiple video and audio metadata
- Supports multiple video and audio watermarks
- Supports multiple video and audio overlays
- Supports multiple video and audio filtersa
